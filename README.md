# 🤖 Mood Based Chatbot

A fun AI chatbot built with **Streamlit + LangChain + Hugging Face** where you can choose the bot’s personality before chatting.

Instead of talking to a normal assistant, you can switch the chatbot’s mood and see how its replies change.

## 🎭 Available Modes

* 😡 **Angry Mode** – replies aggressively and impatiently
* 😂 **Funny Mode** – adds jokes and humor in every response
* 😢 **Sad Mode** – responds emotionally and sadly

This project is made for learning prompt engineering, personality control, and chatbot UI development.

---

## 🚀 Features

* Clean Streamlit chat interface
* Real-time conversation
* Multiple personality modes
* Powered by Hugging Face open-source model
* Uses LangChain message memory format
* Easy to customize with new moods

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/mood-chatbot.git
cd mood-chatbot
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## 🔑 Environment Variables

Create a `.env` file in the root folder:

```env
HUGGINGFACEHUB_API_TOKEN=your_token_here
```

Get your free token from Hugging Face.

---

## ▶️ Run Locally

```bash
streamlit run streamlit_app.py
```

---

## 🌐 Deploy on Streamlit Cloud

1. Push project to GitHub
2. Open Streamlit Community Cloud
3. Select your repository
4. Add your token in **Secrets**
5. Deploy 🚀
